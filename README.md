# セコカン PRサイト

株式会社ダイトクの施工管理サービス「セコカン」を紹介する独立したWebサイトです。

白・ティールを基調に、LINEグループで利用するセコカンBotを中心に紹介しています。
ロゴは初版の提案デザインです。導入実績・価格など未確定の数字は掲載していません。

## ページの構成

- 現場の情報をつなぐトップページ
- セコカンBotの利用イメージ
- 写真管理・黒板管理・図面と工程・ToDoと質疑の切り替え表示
- Web・スマホアプリ・LINEの使い分け
- AI支援の開発予定
- 導入の流れ・料金の案内・FAQ・メールによる導入相談

掲載されている管理画面・LINEの会話は説明用のイメージです。
実際のセコカンシステムやLINE Webhookには接続していません。
お問い合わせボタンは `info@daitoku-inc.com` 宛てのメールアプリを開きます。

## GitHub Pages

本リポジトリの `docs/` が公開ファイルです。
GitHubの **Settings → Pages** で **Deploy from a branch** を選び、
ブランチを **main**、フォルダを **/docs** にして保存してください。

## 編集

- `docs/index.html`：紹介文・ページ構造
- `docs/style.css`：デザインとレスポンシブ表示
- `docs/script.js`：機能紹介のタブ切り替え・スマホメニュー

Noto Sans JPをGoogle Fontsから読み込みます。読み込めない場合は端末の標準サンセリフ書体で表示されます。
追加パッケージ・ビルド・サーバーは不要です。
